# JavaOOP — Πρόοδος μόνο κατά την επίσκεψη

Η εφαρμογή περιλαμβάνει 15 θεματικές ενότητες, 16 βήματα ανά ενότητα και 5 επίπεδα ανά βήμα.

**Νέος κανόνας προόδου:** Οι σωστές απαντήσεις και η πρόοδος διατηρούνται όσο ο φοιτητής χρησιμοποιεί την ανοιχτή σελίδα. **Κλείσιμο και εκ νέου άνοιγμα, απομάκρυνση και επιστροφή ή ανανέωση (F5)** ξεκινούν από την Ενότητα 1, Βήμα 1, Επίπεδο 1, με 0% πρόοδο. Δεν αποθηκεύονται απαντήσεις ή πρόοδος σε localStorage/sessionStorage. Αν ο φοιτητής απλώς αλλάξει καρτέλα, η πρόοδος δεν χάνεται.

Για άνοιγμα χωρίς σύνδεση χρησιμοποίησε το αυτοτελές `JavaOOP_Anoixe_Edo.html`.

Για GitHub Pages ανέβασε τα `index.html`, `styles.css`, `images.js`, `data.js` και `app.js` στον ριζικό φάκελο του repository. Ενεργοποίησε Settings → Pages → Deploy from a branch → main → /(root). Η εφαρμογή παραμένει δημόσια προσβάσιμη, εκτός αν υπάρχει ανεξάρτητος έλεγχος πρόσβασης.

Οι έλεγχοι πληκτρολογημένου κώδικα είναι εκπαιδευτικοί και δεν εκτελούν πραγματικό compiler Java.
